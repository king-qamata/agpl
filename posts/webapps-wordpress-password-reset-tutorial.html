Resetting a WordPress Admin Password on App Service Using SSH and WP-CLI

Beginner WordPress · WP-CLI 5 min read

A locked-out WordPress admin account is a routine operational task, but the fix looks different on App Service than on a typical shared host — no phpMyAdmin by default, no direct file manager. This covers the SSH + WP-CLI path, which is faster and safer than editing the database directly.

Before you start
  • A WordPress site on Azure App Service Linux with SSH enabled
  • Contributor access to the App Service resource

  1. Open the SSH console

    In the portal, go to your App Service → SSH (under Development Tools), or connect via https://<app-name>.scm.azurewebsites.net/webssh/host. This drops you into a shell inside the running container.

  2. Navigate to the WordPress root

    Confirm you're in the directory containing wp-config.php — typically /home/site/wwwroot on App Service Linux.

    bash
    cd /home/site/wwwroot
ls wp-config.php

  3. Confirm WP-CLI is available

    Many WordPress-on-App-Service images include WP-CLI already; if not, it can be downloaded directly as a phar file for one-off use.

    bash
    wp --info

# if not installed:
curl -O https://raw.githubusercontent.com/wp-cli/builds/gh-pages/phar/wp-cli.phar
chmod +x wp-cli.phar
php wp-cli.phar --info

  4. List users to find the account

    Confirm the exact username or ID for the locked-out account before resetting — WP-CLI operates on user login or ID, and getting this wrong resets the wrong account.

    bash
    wp user list --role=administrator

  5. Reset the password

    bash
    wp user update admin --user_pass="a-new-strong-password"

  6. Verify login

    Log in at /wp-admin with the new password to confirm the reset took effect before closing the SSH session.

Result: admin access recovered without touching the database directly — safer and faster than the phpMyAdmin-based password hash edit that's the usual fallback on hosts without SSH access.
